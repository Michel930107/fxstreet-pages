Añadir un nuevo XML
  1. Sube el XML a la carpeta data/.
  2. Edita pages.json y añade una entrada como esta:
{
  "id": "eurusd",
  "title": "EUR/USD",
  "description": "Símbolos TeleTrader vinculados a este asset.",
  "category": "Asset",
  "query": "EURUSD",
  "source": "data/eurusd.xml"
}

Guarda los cambios. El índice y la plantilla se actualizarán automáticamente.
